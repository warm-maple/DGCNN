# 赛道一设计思路

本方案面向 ModelNet40 点云分类任务。每个输入点包含三维坐标和法向量信息，格式为 `x,y,z,nx,ny,nz`。目标是从点云整体几何结构中提取有效特征，并预测三维物体类别。

预处理阶段先将点云缓存为数组文件，减少训练时反复读取 txt 的开销。每个样本固定采样 1024 个点，对坐标做中心化和单位球归一化，对法向量重新归一化。训练时加入随机点 dropout、随机缩放、随机平移和小幅 jitter，增强模型对采样扰动、尺度变化和噪声的鲁棒性。

模型采用 DGCNN 分类网络。DGCNN 在特征空间中动态构建 k 近邻图，使用 EdgeConv 提取局部几何关系，再通过全局最大池化和平均池化形成物体级特征。相比基础 PointNet，DGCNN 能显式建模点与邻域点之间的相对结构；同时使用坐标和法向量也能提升模型对物体表面几何的表达能力。本实现使用 `k=20`、四层 EdgeConv 和 1024 维全局嵌入。

训练使用 PyTorch + CUDA，优化器为 SGD，初始学习率 0.1，momentum 0.9，weight decay 1e-4，采用 cosine 学习率衰减和 label smoothing。训练分为两个阶段：第一阶段训练标准 DGCNN 基线；第二阶段从最佳基线权重继续微调，引入类别均衡采样和轻量类别权重，以提升小样本类别的识别效果。训练过程中分别保存整体准确率最优、类别平均准确率最优和综合表现最优的权重。

最终推理时加载类别均衡微调后的权重，对同一样本进行多次采样投票，降低单次随机采样带来的预测波动。输出文件为无表头 CSV，每行格式为 `样本id,预测类别`。
