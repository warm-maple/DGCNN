# 赛道一设计思路

本方案面向 ModelNet40 点云分类任务。每个样本由点云表示，每个点包含三维坐标和法向量信息，格式为 `x,y,z,nx,ny,nz`。任务目标是从点云的局部几何结构和整体形状分布中提取判别特征，预测物体所属的 40 个类别之一，并输出符合要求的 `样本id,预测类别` CSV 文件。

数据预处理阶段先读取每个 `.txt` 点云文件，并缓存为数组格式，减少训练和推理时反复解析文本带来的开销。每个样本固定采样 1024 个点；若点数不足则重复采样补齐，若点数较多则随机采样。坐标部分先做中心化，再缩放到单位球范围内，以减弱物体原始位置和尺度差异的影响；法向量部分重新归一化，保证方向信息稳定。训练时使用随机点 dropout、随机缩放、随机平移和小幅 jitter，使模型对点云缺失、采样扰动和轻微噪声更鲁棒。

模型采用 DGCNN 分类网络。DGCNN 会在特征空间中动态构建 `k=20` 的近邻图，并通过 EdgeConv 学习中心点与邻域点之间的相对几何关系。多层 EdgeConv 可以逐步从局部边特征过渡到更高层的形状语义特征；随后使用全局最大池化和平均池化汇聚物体级表示，再经过全连接分类头输出 40 类概率。相比只独立编码单点特征的基础 PointNet，DGCNN 更适合表达点云中的局部结构；同时使用坐标和法向量，有助于模型理解物体表面的朝向、边缘和曲面变化。

训练分为两个阶段。第一阶段使用 SGD 优化器、cosine 学习率衰减和 label smoothing 训练基础 DGCNN，使模型获得稳定的整体分类能力。第二阶段从第一阶段较优权重继续微调，加入类别均衡采样和类别加权损失，重点提升样本数量较少或容易混淆类别的识别效果。训练过程中使用验证集指标选择权重，最终提交包保留两阶段表现较好的 `best.pt`，用于后续集成推理。

最终推理时加载第一阶段和第二阶段权重，并按 `0.5/0.5` 进行加权融合。为了降低单次随机采样造成的预测波动，对同一样本使用固定 seed 进行 7 次随机采样投票，累加各次 logits 后取最大概率类别作为最终预测。同时启用 CUDA 混合精度以提升推理速度。最终结果保存为无表头 CSV 文件，每行格式为 `样本id,预测类别`。
