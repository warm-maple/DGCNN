# 赛道一设计思路

本方案面向 ModelNet40 点云分类任务。每个输入样本由若干点组成，每个点包含三维坐标和法向量信息，格式为 `x,y,z,nx,ny,nz`。目标是从点云整体几何结构中提取有效特征，并预测三维物体类别。

预处理阶段先将点云缓存为数组文件，减少训练和推理时反复读取文本文件的开销。每个样本固定采样 1024 个点，对坐标进行中心化和单位球归一化，并对法向量重新归一化。训练时加入随机点 dropout、随机缩放、随机平移和小幅 jitter，增强模型对采样扰动、尺度变化和噪声的鲁棒性。

模型采用 DGCNN 分类网络。DGCNN 在特征空间中动态构建 k 近邻图，通过 EdgeConv 提取局部几何关系，再经过全局最大池化和平均池化得到物体级特征。相比只独立处理单点特征的基础 PointNet，DGCNN 能显式建模点与邻域点之间的相对结构；同时使用坐标和法向量可以提升模型对物体表面几何的表达能力。本实现使用 `k=20`、四层 EdgeConv 和 1024 维全局嵌入。

训练分为两个阶段。第一阶段使用 SGD、cosine 学习率衰减和 label smoothing 训练 DGCNN 基线；第二阶段从第一阶段较优权重继续微调，加入类别均衡采样和类别加权损失，以提升小样本类别的识别效果。最终提交包保留两阶段验证表现较好的 `best.pt` 权重，用于后续加权集成推理。

最终推理时加载第一阶段和第二阶段权重，按 `0.5/0.5` 加权融合。对同一样本使用固定 seed 执行 7 次随机采样投票，降低单次采样带来的预测波动，并启用 CUDA 混合精度以兼顾准确率和运行速度。输出文件为无表头 CSV，每行格式为 `样本id,预测类别`。
