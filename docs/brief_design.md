# ModelNet40 点云分类设计思路

本项目任务是根据点云样本预测三维物体类别。每个点包含 `x, y, z, nx, ny, nz` 六维信息，其中前三维为空间坐标，后三维为法向量。

## 数据预处理

训练和推理时，每个样本固定采样 1024 个点。对点云坐标进行中心化和单位球归一化，使不同尺度、不同位置的物体输入保持一致；对法向量重新归一化，保证方向特征稳定。训练阶段加入随机点 dropout、随机缩放、随机平移和小幅 jitter，以提升模型对采样扰动和噪声的鲁棒性。

## 模型结构

模型采用 DGCNN（Dynamic Graph CNN）。DGCNN 在点云特征空间中动态构建 k 近邻图，通过 EdgeConv 学习点与邻域点之间的局部几何关系。相比基础 PointNet 只做全局特征聚合，DGCNN 能更好利用局部结构信息。本实现同时使用坐标和法向量作为输入，以增强几何表达能力。

## 训练策略

训练严格只使用老师给出的训练集，并从训练集中按类别分层划分训练子集和验证子集。第一阶段训练标准 DGCNN 基线；第二阶段从第一阶段验证集最优权重继续微调，引入类别均衡采样和类别加权损失，重点提升 Class Accuracy。训练过程中保存整体准确率最优、类别平均准确率最优、综合表现最优、最后一轮、每 10 轮快照以及验证集综合分前 5 的 checkpoint。所有 `best` 权重均只依据训练集内部验证集选择。

## 推理方式

最终推理加载第一阶段和第二阶段的验证集最优权重，按 `0.5/0.5` 加权融合；对每个测试样本使用固定 seed `2026` 进行 7 次随机采样投票，并使用 CUDA 混合精度加速。输出文件为无表头 CSV，每行格式为：

```text
样本id,预测类别
```
