# ModelNet40 点云分类设计思路

本项目任务是根据点云样本预测三维物体类别。每个点包含 `x, y, z, nx, ny, nz` 六维信息，其中前三维为空间坐标，后三维为法向量。老师提供的训练集经核对与官方 ModelNet40 train split 完全一致，因此使用官方 test split 作为预演集评估模型效果，避免训练和测试样本重叠。

## 数据预处理

训练和推理时，每个样本固定采样 1024 个点。对点云坐标进行中心化和单位球归一化，使不同尺度、不同位置的物体输入保持一致；对法向量重新归一化，保证方向特征稳定。训练阶段加入随机点 dropout、随机缩放、随机平移和小幅 jitter，以提升模型对采样扰动和噪声的鲁棒性。

## 模型结构

模型采用 DGCNN（Dynamic Graph CNN）。DGCNN 会在点云特征空间中动态构建 k 近邻图，通过 EdgeConv 学习点与邻域点之间的局部几何关系。相比基础 PointNet 只做全局特征聚合，DGCNN 能更好利用局部结构信息，因此更适合 ModelNet40 分类任务。本实现同时使用坐标和法向量作为输入，以增强几何表达能力。

## 训练策略

训练分为两个阶段。第一阶段使用标准 DGCNN 在老师训练集上训练，优化器为 SGD，采用 cosine 学习率衰减和 label smoothing。第二阶段从第一阶段最佳权重继续微调，引入类别均衡采样和轻量类别权重，重点提升小样本类别的 Class Accuracy。训练过程中分别保存整体准确率最优、类别平均准确率最优和综合表现最优的权重。

## 推理与结果

最终推理使用类别均衡微调后的 `best_class.pt` 权重，并对每个测试样本进行多次随机采样投票，降低单次采样带来的波动。预演集上推荐方案达到：

- Test Instance Accuracy：92.22%
- Class Accuracy：91.10%
