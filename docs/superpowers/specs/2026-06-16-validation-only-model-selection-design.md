# 基于训练集验证划分的两阶段训练设计

## 目标

在保持现有 DGCNN 网络、数据增强和两阶段训练策略不变的前提下，消除官方测试集参与模型选择造成的数据泄漏。所有梯度更新和最佳权重选择都只使用老师提供的训练数据：

```text
F:\Python Project\pointnet\dataset\train
```

官方 ModelNet40 test split 仅在训练、权重选择和推理配置全部冻结后进行一次最终效果评估。

## 数据划分

从老师训练集的 40 个类别中分别进行确定性的分层划分：

- 每个类别约 90% 样本进入训练子集。
- 每个类别约 10% 样本进入验证子集。
- 使用固定划分种子 `2026`。
- 每个类别至少保留一个验证样本。
- 训练集和验证集样本 ID 必须无交集。
- 将划分结果保存到缓存元数据和运行目录，确保两个训练阶段使用完全相同的划分。

训练缓存名称为 `teacher_train_split`，验证缓存名称为 `teacher_val_split`。官方测试缓存名称为 `official_test`，名称和用途必须与验证集明确区分。

## 第一阶段

第一阶段从随机初始化开始训练标准 DGCNN：

- 输入为 1024 个点的六维特征 `x,y,z,nx,ny,nz`。
- 仅从 `teacher_train_split` 加载带数据增强的训练样本。
- 每轮仅在 `teacher_val_split` 上计算 Instance Accuracy 和 Class Accuracy。
- `best.pt`、`best_class.pt`、`best_balanced.pt` 只能根据验证集指标保存。
- `last.pt` 保存最后一轮状态。

网络结构、优化器、学习率衰减、label smoothing 和数据增强沿用现有第一阶段配置。

## 第二阶段

第二阶段从第一阶段由验证集选出的 `best.pt` 加载模型参数，重新创建优化器和学习率计划：

- 仍只使用 `teacher_train_split` 进行梯度更新。
- 继续使用 `teacher_val_split` 选择最佳权重。
- 保留类别均衡采样、类别加权损失和较低学习率微调策略。
- 不读取官方 test 指标决定训练轮数、权重或超参数。

## 官方测试评估

训练完成并冻结最终选择后，使用独立评估命令加载指定权重，在官方 ModelNet40 test split 上运行一次：

- 评估结果保存为单独的 `official_test_eval.json`。
- 该结果仅用于估计最终泛化能力。
- 不根据该结果继续训练、改变集成权重、选择其他 checkpoint 或修改推理参数。
- 最终报告同时保留验证集指标和官方测试集指标，并明确两者用途。

## 清理与兼容

新克隆项目中已有的旧权重、旧预测 CSV 和旧评估结果将被删除，避免与无泄漏实验混淆。原项目 `F:\Python Project\pointnet` 保持不变，仅作为训练数据和官方数据的只读来源。

推理接口继续使用现有 `predict.py` 和 `predict_advanced.py`。训练完成后再根据无泄漏验证流程产生的新权重更新默认推理脚本，旧权重不会混入新实验。

## 验证要求

自动化测试必须覆盖：

1. 相同种子产生相同划分。
2. 训练集与验证集无交集，二者并集等于老师训练集。
3. 每个类别同时存在训练和验证样本。
4. 训练流程默认评估 `teacher_val_split`，而不是官方 test。
5. 官方 test 仅由独立最终评估入口读取。
6. 第二阶段复用第一阶段的划分清单。

完整训练开始前运行小规模 smoke test，确认缓存、反向传播、验证评估和 checkpoint 保存均可正常执行。
