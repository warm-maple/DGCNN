# 实验结果记录

本文件记录训练过程中保留的验证集结果，便于选择现场验收时的默认命令。

## 数据划分

训练数据按类别分层划分：

- 训练子集：8858 个样本
- 验证子集：985 个样本
- 划分种子：2026

## 结果

| 方案 | 评估集 | Votes | Instance Accuracy | Class Accuracy |
| --- | --- | ---: | ---: | ---: |
| 第一阶段 `best.pt` | 验证集 | 1 | 94.01% | 91.37% |
| 第二阶段 `best.pt` | 验证集 | 1 | 93.20% | 91.83% |
| 第一阶段 + 第二阶段 0.5/0.5 | 验证集 | 3 | 93.71% | 91.53% |
| 第一阶段 + 第二阶段 0.5/0.5 | 验证集 | 7 | 93.81% | 91.81% |

最终推荐配置为两阶段 `0.5/0.5` 集成、7 票随机采样，并固定使用 `--seed 2026`。
